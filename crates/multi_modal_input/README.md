# ohos-multi-modal-input-binding

Safe Rust bindings for OpenHarmony Multimodal InputKit (key state queries, global hotkey monitoring, and window pointer styles/visibility).

## Install

```shell
cargo add ohos-multi-modal-input-binding
```

## Usage

```rust
use ohos_multi_modal_input_binding as input;

// Query key states, register API 14+ global hotkeys with `HotkeyMonitor`,
// or manage API 22+ pointer visibility and cursor styles.
```
