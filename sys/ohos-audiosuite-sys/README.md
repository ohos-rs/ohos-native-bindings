# ohos-audiosuite-sys

This crate provides low-level sys bindings for the OHAudioSuite module in OpenHarmony.

The C API bindings are generated by `tools/generate` from:

- `ohaudiosuite/native_audio_suite_base.h`
- `ohaudiosuite/native_audio_suite_engine.h`

The bindings are generated from the HarmonyOS SDK headers by `tools/generate`.
The API surface is gated by the corresponding `api-*` Cargo features.

## Install

```shell
cargo add ohos-audiosuite-sys
```

The C API is available from API version 22. Use `api-26` to enable the complete
API surface currently supported by the repository.
